# Security

## Reporting a website security issue

Please email **cyberbeesolutionsltd@gmail.com** with the subject **Website security report**.

Do not conduct intrusive testing, denial-of-service activity, social engineering, credential attacks or access to data without prior written authorisation. This repository and website do not grant permission to test any connected service.

Include a clear description, affected page or component, reproduction steps that avoid harm, and your preferred contact details.
